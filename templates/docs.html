Documentation

AICID assigns persistent, citable identifiers to AI agents that contribute to research. This guide explains how to use the platform via the website and via the REST API.

The identifier

An AICID looks like AICID-5282-9748-4313-4513: a prefix, 15 digits in hyphenated groups of four, and an ISO 7064 MOD 11-2 check character — deliberately ORCID-shaped.

The normative format specification (grammar, checksum algorithm, canonical form, resolution URL, persistence guarantees) is published at /docs/identifier and kept in the repository as docs/identifier.md. It is the document to cite when integrating AICID into validation code or metadata schemas.

Using the Website

The web interface at aicid.net lets you register agents, browse profiles, and search the registry — no programming required.

1. Register an agent

  1. Go to /register or click Register an Agent on the homepage.
  2. Fill in the required fields:
    • Agent name — a descriptive name for the AI agent (e.g. ResearchBot v2).
    • Human operator — name of the person or team responsible for the agent.
    • Operator email — used to link all your agents to a single account.
  3. Optionally provide the base model, version, and agent harness.
  4. Click Register Agent. The assigned AICID (e.g. AICID-5282-9748-4313-4513) is shown and a one-time link is emailed to the operator address; opening it publishes the public profile. If you are already logged in as that operator, the profile is published immediately.
  5. No password is required. Management access is claimed later by verifying the operator email.

2. Manage a profile

  1. Go to /auth/login or click Manage in the top navigation.
  2. Enter the same operator email used during registration.
  3. Open the emailed one-time login link or paste the one-time code into the form.
  4. After verification, AICID sets a short-lived HTTP-only browser session so you can edit your profiles at /manage.

3. View a profile

Every registered agent has a public profile page at https://aicid.net/agents/<AICID>. Example: aicid.net/agents/AICID-5282-9748-4313-4513 .

The profile displays:

  • Agent name, type, base model, and organization.
  • Keywords and description.
  • Linked works (papers, datasets, software) with DOIs.
  • Employment/deployment affiliations and funding information.
  • A JSON export link for machine-readable access.
  • A Self-registered badge for agents that registered themselves, and a Verified operator badge once a human has claimed them.

4. Search the registry

Go to /search-page and type any keyword, agent name, organization, or description term. Results show all public agents matching the query. Clicking a result opens the agent's profile page.
